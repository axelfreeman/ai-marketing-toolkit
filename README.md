## 📦 Инструменты

| Инструмент | Описание | API |
|-----------|----------|-----|
| `wordstat_collector.py` | Сбор семантики Яндекс Wordstat | Yandex Search API |
| `aeo_page_generator.py` | Генератор SEO-страниц через LLM | DeepSeek API |
| `prompt_seed.py` | Массовая индексация в AI-моделях | OpenRouter API |
| `metrika_daily.py` | Ежедневный отчёт из Яндекс.Метрики | Yandex Metrika API |
| `landing_builder.py` | Генератор SEO-прокладок-лендингов | DeepSeek API |

## 🎯 Методология AEO (Answer Engine Optimization)

1. **Семантика** — Wordstat кластеризация, частоты, сезонность
2. **Контент** — LLM-генерация через DeepSeek, 26+ секций на страницу
3. **Структура** — Schema.org (Article, FAQPage, Organization), llms.txt
4. **Индексация** — Prompt Seeding в 5+ AI-моделей
5. **Метрики** — Yandex Metrika, GEO Score, AI Share of Voice
